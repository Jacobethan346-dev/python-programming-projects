# Create and save a document in Word for Mac

**End-user support writing sample.**  
**Audience:** People who are new to Word for Mac  
**Task:** Create a document and save an editable .docx copy in a known local folder

## Before you begin

Open an installed and activated copy of Microsoft Word. Have your document text ready and choose a folder where you want to keep the file. This example uses Documents.

## Create the document

1. On Word's start screen, select **Blank Document**. If a separate confirmation window appears, choose **Create**.
2. Type your text. Press Return when you want a new paragraph; Word wraps ordinary lines automatically.
3. Press **Command+S** to save the new document.

## Choose a name and location

1. Enter a descriptive name, such as `Training_Notes.docx`, in the filename field.
2. Choose **Documents**, or another folder you can identify later. Expand the location chooser if the folder list is hidden.
3. Keep **Word Document (.docx)** selected as the format when you want an editable Word file.
4. Choose **Save**.
5. Confirm that the document's title now shows your chosen filename. To verify the location, find and reopen the file from its folder in Finder.

Press Command+S again after making changes. For an existing named file, this normally updates that file without asking you to choose another name.

## Troubleshooting

| Problem | What to check |
| --- | --- |
| Command+S does not open a Save window | The document may already be named; saving then updates the existing file. Check the document title and selected folder. |
| The folder list is hidden | Expand the location chooser beside **Where**, if shown, to reveal more locations. |
| Word asks whether to replace a file | Choose **Cancel** if you need to preserve the original, then use a different filename. |
| You cannot find the saved document | Search Finder for its chosen filename, then check the location you selected when saving. |
| You expected AutoSave to preserve every change | Check whether AutoSave is available and turned on for this file. Save explicitly with Command+S when appropriate. |

## Confirm the task is complete

You can locate the .docx file in the intended folder, reopen it in Word, and see the latest saved text.

## Scope of this sample

This article adapts an existing Word-for-Mac tutorial into a concise support article. Exact labels and available storage locations can vary by Word version and account configuration. The source screenshots and personal file examples are omitted.
